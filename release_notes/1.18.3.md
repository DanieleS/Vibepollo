# Vibepollo 1.18.3 - 2026-07-19

Notice: Vibepollo may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

This release contains everything in Vibepollo 1.18.2 plus the changes below.

## Changes
- Playnite's play record is now passed through to clients: `/appmetadata` serves `last_played` and `playtime_minutes` for synced games, alongside the metadata it already carried. Playnite and the host had both tracked these all along, but they were never mirrored into `apps.json`, so nothing downstream could see them. A client can only ever know the sessions it launched itself; these cover sessions played at the PC too, which is what lets a client order a library by when a game was really last played. Nothing changes for existing clients — the fields are additive and simply ignored by anything that does not ask for them.
