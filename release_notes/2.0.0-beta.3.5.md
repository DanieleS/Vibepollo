# Vibepollo 2.0.0-beta.3.5 - 2026-09-24

Notice: Vibepollo may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

This release fetches game telemetry profiles by itself. Everything else in 2.0.0-beta.3.4 is
unchanged.

## Changes
- Telemetry profiles now come from the [scry-profiles](https://github.com/DanieleS/scry-profiles)
  registry. When a game starts, Vibepollo downloads the registry's index and only the profiles
  for that game's executable, checks each against its hash, and keeps them in a `scry-registry`
  folder next to the configuration, so they keep working offline. The index is refreshed once a
  day.
- `scry_profiles_dir` is still read, and a profile placed there is tried before the registry's.
  That is how to try a profile before it is published, and it also means an old profile left
  there keeps winning: remove it once the registry covers the game.

## Known issues
- When the game loses focus, telemetry stops and the client panel goes blank for a moment
  until the game is back in the foreground.
- IGDB metadata has not yet been exercised against a live account.
- Releases from this fork are unsigned.
