# Vibepollo 2.1.0 - 2026-10-09

Notice: Vibepollo may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

Play statistics and achievements from Playnite, served to paired clients. Ratatoskr 20.2.9
shows them in its library, and toasts achievements while you stream.

## Changes
- Play statistics for paired clients, on Windows with the Playnite connector. A new
  `/appstats` endpoint answers for a week, month or year (total, daily or monthly buckets,
  sessions, most played, library totals and games worth resuming) and for a single game.
  Play sessions come from Playnite's [GameActivity](https://github.com/Lacro59/playnite-gameactivity-plugin)
  extension; without it, only Playnite's totals, the resume shelf and achievements are served.
- Achievements from Playnite's [SuccessStory](https://github.com/Lacro59/playnite-successstory-plugin)
  extension: `/appachievements` for a game, `/appachievements/recent` for the latest unlocks,
  and `/appachievementicon` for the icons SuccessStory keeps on disk.
  - Like `/appmetadata`, a client only sees names and entries for the games its app list shows
    it. The endpoints answer 404 off Windows and before the connector has reported its paths.
- The Playnite connector (0.5.1) now tells Vibepollo where GameActivity's and SuccessStory's data
  live, and Vibepollo keeps those paths and the last full library so statistics answer before
  Playnite reconnects after a restart. Update the connector when Playnite offers it.
- The web UI lists GameActivity and SuccessStory under "Compatible extensions" in the Playnite
  integration, each with a badge saying whether its data was found, and each can be turned off
  (`playnite_gameactivity`, `playnite_successstory`).
- scry is pinned to 0.1.0-alpha.7: it reads the Final Fantasy VII Rebirth profile, and attaching
  to that game drops from over a minute to under a second.

## Known issues
- When the game loses focus, telemetry stops and the client panel goes blank for a moment
  until the game is back in the foreground.
- SuccessStory usually refreshes a game's achievements only when the game closes, so unlocks
  can show up on clients after the session rather than during it.
- IGDB metadata has not yet been exercised against a live account.
- Releases from this fork are unsigned.
