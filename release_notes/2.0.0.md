# Vibepollo 2.0.0 - 2026-10-02

Notice: Vibepollo may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

This release brings the fork up to upstream Vibepollo 2.0.0 stable. Everything this fork adds,
game telemetry with scry, IGDB metadata and the Playnite passthrough, is unchanged from
2.0.0-beta.3.5; the rest below comes from upstream.

## Changes
- Merged upstream Vibepollo 2.0.0, which picks up everything from 2.0.0-beta.4 onwards.
- Native Linux host for Arch Linux and CachyOS (beta), running on KDE Plasma 6 Wayland with
  managed virtual displays, HDR and Remote Monitor sessions. This fork attaches its Arch package
  to the release; install it with `pacman -U`. Upstream's signed pacman repository and
  `linux_install.sh` install upstream's build, not this one.
- PyroWave, a GPU wavelet codec for very low latency on a fast wired LAN, on Windows and Linux.
  It needs Nonary's [VRR Moonlight Client fork](https://github.com/Nonary/moonlight-qt).
- Better VRR capture: a fixed 1000 Hz Windows virtual-display mode is picked automatically when
  the client asks for VRR pacing, and Windows Graphics Capture follows game presentation more
  closely.
- Vibepollo's own Windows virtual gamepad driver, which emulates Xbox Series, Xbox One,
  DualSense, DualShock 4 and Switch Pro controllers without ViGEmBus. Select `vhf` under
  Input → Gamepad.
- Remote Monitor and Remote Input: a second Moonlight device can join as an extra display, or
  as input without video, next to the main session.
- Wireless DualSense haptics and adaptive triggers, and DualShock 4 emulation, on Linux.

## Fixes
- Kept the metadata endpoint's catalogue identical to the 2.0.0 app list, so a client only gets
  descriptions for the apps its app list shows it, and never for the host's control entries.
- Preserved Remote Monitor and Remote Input sessions when games ended, and stopped stale virtual
  gamepad reports from replaying released buttons and triggers.
- Preserved legacy Sunshine settings during migration and valid pairing timestamps across saves.

## Known issues
- When the game loses focus, telemetry stops and the client panel goes blank for a moment
  until the game is back in the foreground.
- IGDB metadata has not yet been exercised against a live account.
- Releases from this fork are unsigned.
