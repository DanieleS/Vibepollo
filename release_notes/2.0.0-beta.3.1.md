# Vibepollo 2.0.0-beta.3.1 - 2026-09-18

Notice: Vibepollo may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

Notice: this is a prerelease, and the first build of this fork on the 2.x line. The metadata
work below has never run against a real IGDB account — it compiles, its portable half is
covered by tests, and the rest is waiting for its first contact with the live API.

This release is upstream Vibepollo 2.0.0-beta.3 plus the changes below.

## Changes
- Moved this fork onto upstream's 2.0 line. That brings Linux support with it: the Arch
  package builds, so CachyOS and other Arch derivatives are now a supported host.
- Game metadata no longer belongs to Playnite. Descriptions, genres, release dates, scores and
  cover art are now held in one provider-agnostic container that Playnite, IGDB and the user
  all write to, and an existing library keeps everything it already had.
- Added IGDB as a metadata source, so games are described the same way whichever launcher they
  came from — including games no launcher knows anything about. It needs a free Twitch
  application; the client ID goes in the settings and the client secret is stored in a file of
  its own, because reading the settings over the API returns the configuration file as it
  stands.
- Games are matched on their store ID where IGDB indexes the store (Steam, GOG, Epic, the
  Microsoft Store, itch.io), which is exact. Ubisoft Connect, the EA app and Battle.net have no
  IGDB IDs, so their games fall back to a title search that only accepts an exact match — a
  near miss is left undescribed rather than guessed at.
- Added a per-app metadata editor to the new web UI: search IGDB by name, pick the right
  record, or write the fields by hand. Anything edited by hand survives every later library
  sync instead of lasting until the next one.
- Game telemetry (scry) is now available in the new web UI as well as the old one, with the
  per-client permission shown in the device list.
- The bundled Playnite extension now reports each game's store ID alongside the plugin name.
  Reinstall the extension from the Integrations page to pick this up; without it, Playnite
  games can only be matched by title.

## Fixes
- Fixed the running application's name being reported to callers that had just been told the
  host was free. It is now gated exactly like the other active-game fields.
- Fixed several strings and one setting that went missing when the web UI split in two: the
  Playnite hidden-games options, the telemetry labels, and the telemetry permission on the
  pairing page, which had drifted out of step with the host.

## Known issues
- IGDB metadata has not yet been exercised against a live account. If matching misbehaves, the
  Integrations page has a "Test credentials" button and every app can be corrected by hand.
- Releases from this fork are unsigned.
