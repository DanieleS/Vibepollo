# Vibepollo 2.0.0-beta.3.3 - 2026-09-20

Notice: Vibepollo may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

This release adds one Playnite option and fixes the web UI around it. Everything else in
2.0.0-beta.3.2 is unchanged.

## Changes
- Added "Take game metadata from Playnite", on by default. Playnite describes a synced game
  unless IGDB or a manual edit already claimed it, which makes Playnite the first source for
  every new game and IGDB only the second. Turning this off says Playnite is never the source:
  description, genres, companies, release date, scores and background art are left for IGDB to
  fill in, and a game Playnite described earlier keeps what it has until a forced pass replaces
  it. Last played and playtime are still taken from Playnite either way, because only Playnite
  watched the game run.
- The switch is in the game metadata card of the new web UI on Windows hosts, and in the
  Playnite tab of the classic one.

## Fixes
- Fixed the new option still letting Playnite's background art through on a newly synced game.
  Every description of the option lists background art among the fields it covers, so a game
  left undescribed no longer picks up a Playnite hero image either.
- Fixed the same switch reading as off, and as an unsaved change, when the host reported its
  platform after the metadata card had already loaded.

## Known issues
- IGDB metadata has not yet been exercised against a live account.
- Releases from this fork are unsigned.
