# Scirocco 3.0.0 - 2026-10-15

Notice: Scirocco may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

The fork is now Scirocco, the Windows host for Zefiro, and an idle client can no longer freeze
pairing and launch for the others.

## Changes
- An idle client connection can no longer block the host's HTTPS thread. The host used to wait
  for the client's TLS close notice when dropping a connection, and a client that left one open
  froze pairing, launch and server info for every other client until it went away. Ported from
  Frametop's fork.
- The host is now called Scirocco where you see it: the Start menu, Programs and Features, the
  tray menu, the installer and the web UI, with a new application icon (the fox on cream) and
  new tray and web UI icons. The tray icon carries a green, blue or grey badge while streaming,
  paused or locked.
- The web UI now opens the v2 interface by default; the classic one stays at `/?classic`, where
  the v2 sidebar's link leads.
- The Playnite extensions text in the web UI names Zefiro, the client's new name.

## Known issues
- When the game loses focus, telemetry stops and the client panel goes blank for a moment
  until the game is back in the foreground.
- SuccessStory usually refreshes a game's achievements only when the game closes, so unlocks
  can show up on clients after the session rather than during it.
- IGDB metadata has not yet been exercised against a live account.
- Releases from this fork are unsigned.
