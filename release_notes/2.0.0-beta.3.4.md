# Vibepollo 2.0.0-beta.3.4 - 2026-09-24

Notice: Vibepollo may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

This release is a round of fixes from a review of game telemetry and game metadata, and it
updates the bundled scry to 0.1.0-alpha.4.

## Changes
- Game telemetry now reaches the client about as soon as the game is in the foreground. It
  used to take around 30 seconds after a launch from Steam or Playnite, and again after every
  alt-tab or overlay, because the helper was held to a failure it had on the launcher.
- The telemetry snapshot carries the contract the values follow as `contract: {id, version}`,
  so a client can pick its view by what the values mean rather than by the profile name.
- Newly paired clients, and imported devices with no permission mask, no longer receive game
  telemetry unless it is granted to them. Clients already paired keep what they have.
- Game descriptions from IGDB now come with a cover and background art that clients can
  show. Both used to be saved as JPEG, which the endpoints serving art to clients refuse.
- A game whose title IGDB lists more than once, such as a remake, is matched by its release
  year. Without a year it is left for you to link, rather than taking IGDB's first result.

## Fixes
- Fixed telemetry never starting when the profiles directory was entered with a trailing
  backslash.
- Fixed revoking a client's telemetry permission, or turning telemetry off, leaving a stream
  already open running until the session ended.
- Fixed one malformed event from the telemetry helper being able to take the host down, and
  a hot config reload racing the telemetry settings.
- Fixed open telemetry streams writing keepalives in a tight loop after telemetry stopped,
  and a client being able to hold any number of streams at once.
- Fixed the IGDB background pass overwriting newer playtime from Playnite, and undoing manual
  metadata edits made while it ran.
- Fixed saving the app form reverting changes made in the metadata editor.
- Fixed saving the IGDB settings turning Playnite metadata back on. The switch now appears
  only once, in the Playnite section.
- Fixed IGDB staying enabled after being turned off, until the next restart.
- Fixed the Playnite store name overwriting the reason a game was synced, which broke the
  cleanup of installed games and matching by store id.
- Fixed a Playnite library snapshot that lost a batch on the way being used to remove games.
- Fixed image downloads without a timeout, which could leave a truncated or error page on
  disk as a cover, or block every app endpoint while holding the apps file.
- Fixed apps IGDB could not match being searched again on every sync.
- Fixed a Remote Monitor client receiving every app's metadata.
- The telemetry settings in the new web UI show their defaults, and the tick interval is
  limited to what the host accepts (10 to 1000 ms).

## Known issues
- When the game loses focus, telemetry stops and the client panel goes blank for a moment
  until the game is back in the foreground.
- IGDB metadata has not yet been exercised against a live account.
- Releases from this fork are unsigned.
