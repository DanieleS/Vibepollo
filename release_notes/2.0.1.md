# Vibepollo 2.0.1 - 2026-10-03

Notice: Vibepollo may trigger false-positive antivirus alerts.

Notice: builds from this fork are not code-signed, so Windows SmartScreen reports an unknown
publisher on first run. Choose "More info" then "Run anyway" to continue.

A Linux fix on top of 2.0.0. Windows is unchanged.

## Fixes
- Fixed the Linux host never starting on systems with a non-English locale. The session
  controller compared `stat` output against English text, so on an Italian, German or other
  localized system it rejected a valid `/etc/vibepollo/machine.conf` and kept logging
  "machine policy is unavailable or invalid; host is off" while nothing listened on port 47990.
  The controller and the package install and removal scripts now run in the C locale.

## Known issues
- When the game loses focus, telemetry stops and the client panel goes blank for a moment
  until the game is back in the foreground.
- IGDB metadata has not yet been exercised against a live account.
- Releases from this fork are unsigned.
